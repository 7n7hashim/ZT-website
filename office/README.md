# Zaras Travel: office dashboard (design demo)

This folder is the design demo for the internal office dashboard, planned for
**office.zarastravel.co.ke**. **Every customer, phone number and amount in it is fictional.**
It has no data entry and saves nothing.

The finished dashboard will show figures imported from Zaras Travel's own Excel records. Real
financial data must never be added to this public repository.

It has three sections:

- **Overview:** sales and performance charts.
- **Who owes us money:** each customer's balance, phone number, how late they are, and the next follow-up.
- **Follow-ups:** who to contact, most urgent first.

Everything is in `index.html`, with the fonts and logo stored alongside it.
